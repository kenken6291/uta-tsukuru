# うたつくる（uta-tsukuru） v1.0.0

ジャンル・テーマ・声のイメージ・曲風・気持ちを入れると、Gemini が約3分の曲を作詞・作曲し、
Gemini TTS の声と映像演出（自動ビジュアル／Google Earth Studio 撮影指示）までまとめて仕上げる Web アプリです。

## ディレクトリ構成

```
uta-tsukuru/
├── index.html   画面（HTML＋CSS）
├── config.js    GAS URL などの設定（一元管理）
├── app.js       会員認証・曲づくり・ステージ・音声入力
├── engine.js    音楽エンジン（Web Audio：ジャンル別伴奏・ミックス・WAV書き出し）
├── README.md
└── gas/
    └── code.gs  GAS バックエンド（認証・Gemini・TTS・ドライブ保存）
```

## GAS のデプロイ

1. https://script.google.com で新しいプロジェクトを作り、`gas/code.gs` の内容を貼り付ける
2. プロジェクトの設定 → スクリプトプロパティに `GEMINI_API_KEY` を追加（任意で `APP_URL` など）
3. エディタで `setup` を選んで実行 → 権限を承認（シート・ドライブフォルダ・PEPPER が自動作成されます）
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 表示された `.../exec` の URL を `config.js` の `GAS_URL` に貼る

**コードを直したら**「デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」をしないと反映されません（URL はそのまま）。

### 任意のスクリプトプロパティ

| キー | 既定値 | 内容 |
|---|---|---|
| GEMINI_TEXT_MODEL | gemini-2.5-flash | 作詞・作曲・演出のモデル |
| GEMINI_TTS_MODEL | gemini-2.5-flash-preview-tts | 読み上げのモデル |
| GEMINI_THINKING_BUDGET | （空） | 2.5 Flash なら `0` で高速化。対応しないモデルでは空欄 |
| DAILY_GEN_LIMIT | 120 | 1人1日のテキスト生成回数（1曲で5〜8回） |
| DAILY_TTS_LIMIT | 300 | 1人1日の読み上げ生成回数 |
| APP_URL | https://kenken6291.github.io/uta-tsukuru/ | メールに載せるURL |

## GitHub Pages のデプロイ

1. リポジトリ `uta-tsukuru` を作り、`index.html` `config.js` `app.js` `engine.js` を置く（`gas/` は置いても置かなくても可）
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. `https://kenken6291.github.io/uta-tsukuru/` で公開されます

GAS の URL は画面の「設定」からブラウザごとに上書きもできます（config.js より優先）。

## 仕組みのポイント

- **作曲は3段階**：作詞と構成 → 作曲（パターンごとに分割して並列実行し、GAS の時間切れを回避）→ 演出とナレーション
- **約3分に合わせる**：小節数から BPM を自動調整し、足りなければサビをくり返して 160〜210 秒に収めます
- **伴奏**：17ジャンルそれぞれのリズム・ベース・伴奏パターンを engine.js に持ち、Web Audio で合成（音源ファイル不要）
- **歌詞の声**：区間ごとに Gemini TTS で生成し、区間の頭に合わせて重ねます（長いときは少し速めて収めます）
- **指示語の混入防止**：TTS には本文だけを渡し、指示文を付けません。さらにフロントと GAS の両方で「〜で読み上げてください」・見出し・カッコの演出指示を除去します
- **音声入力**：continuous＋自動再開で、無音が設定秒数（既定10秒）続くまで聞き取りを続けます。Android の重複確定にも対応
- **書き出し**：OfflineAudioContext で再生を待たずに高速レンダリング。WAV（44.1kHz ステレオ）をダウンロード、またはドライブへ軽量版（22kHz モノラル）を保存
- **Google Earth Studio**：API がないため、区間ごとの場所・座標・高度・カメラの撮影指示を表で出し、書き出した映像を曲のドライブフォルダに入れると背景に使えます（20MBまで）
- **会員認証**：同意チェック4項目必須／仮パスワードをメール送信／初回ログインでパスワード変更を強制／パスワード再発行（5分に1回まで）／5回失敗で15分ロック／SHA-256＋salt＋pepper（200回ストレッチ）／CacheService セッション（6時間）

## 制限

- Gemini TTS は歌唱ではなく読み上げです。メロディはシンセで演奏し、歌詞は語りとして重ねます
- 実在の歌手の声の再現はしません（声のイメージは作詞の雰囲気と声の選択の参考に使います）
- MailApp の送信数は無料アカウントで1日100通程度です
